# Марк Аврелий: тексты для рассылки

Источник дневных цитат — `../mark.html`, «Наедине с собой. Размышления». В них слова и пунктуация сохранены; HTML-разметка и нестандартные пробелы приведены к обычному тексту.

- `morning/morning.txt` — одно постоянное утреннее сообщение по мотивам идей Марка Аврелия. Это современный авторский текст, а не дословная цитата.
- `day/` — 347 разных дословных цитат для случайной дневной отправки. Здесь есть краткие законченные мысли и полные нумерованные фрагменты. Некоторые темы повторяются, но тексты файлов не совпадают.

Имя `07-15.txt` означает книга VII, фрагмент 15. Если из одного фрагмента взято несколько разных выдержек, к имени добавлен порядковый номер, например `07-15-02.txt`. В каждом дневном TXT хранится одна цитата, без дополнительной подписи или инструкции для бота.

Основные темы дневной подборки: внимание к собственным поступкам, справедливость и отношение к людям, различие между событием и суждением о нём, возвращение к душевному равновесию, ценность настоящего. Эта разметка нужна для рассылки; в оригинальном тексте тематических рубрик нет.
