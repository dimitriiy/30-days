# Telegram-бот

Запуск для разработки: `yarn dev` одновременно поднимает сайт и бота. Отдельный запуск бота: `yarn bot`. Нужен `TELEGRAM_BOT_TOKEN` в `.env` или окружении. В продакшене бот запускается отдельным процессом `telegram-bot` из `pm2.json`. Данные подписок и привычек сохраняются в `bot-data.json`; этот файл не добавляется в Git. Еженедельная резервная копия включает его вместе с `db.json`.

При запуске бот регистрирует нативное меню команд Telegram для личных чатов. При `/start` бот спрашивает местное время утреннего сообщения. Часовой пояс нового пользователя по умолчанию — `Europe/Moscow`. Команда `/timezone` позволяет выбрать другой пояс кнопкой с городом или написать зону IANA, например `Europe/Berlin`; для нескольких российских городов принимается название по-русски. После ответа бот ежедневно отправляет постоянный текст из `mark-quotes/morning/morning.txt` и одну случайную дневную цитату из `mark-quotes/day/` в случайную минуту с 12:00 до 20:59 **по времени пользователя**. `/quote` отправляет дополнительную случайную цитату сразу и не отменяет дневную рассылку. `/time` меняет утреннее время, `/stop` отключает уведомления. При смене зоны все сохранённые часы начинают трактоваться как местное время новой зоны.

`/habit` создаёт привычку на 30 календарных дней и спрашивает название длиной до 180 символов, местное время напоминания и более позднее местное время для отметки результата. Если время напоминания в день создания уже прошло, отсчёт начнётся завтра. В конце дня бот предлагает кнопки «Выполнил» и «Не выполнил»; нажатие можно изменить повторно, пока доступно сообщение. `/habits` и `/progress` показывают 30-дневный чеклист с отметками выполненных, пропущенных, пока не отмеченных и будущих дней, а также счётчики. Неотмеченный день не считается невыполненным автоматически.

Тесты бота находятся в `server/bot/__tests__/`. Проверки: `yarn test:bot`, `npx tsc --noEmit`, `npx eslint server/bot`.
